# Frontend — EDU-Infra Analytics

Frontend React/Vite reconstruído sobre a interface da entrega 14/09.

## Executar

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

A API esperada por padrão é `http://127.0.0.1:8000`.

A aplicação agora inicia pela tela de login e, após autenticação, disponibiliza Dashboard, Laboratórios, Computadores, Indicadores, Relatórios, Configurações e Privacidade.
